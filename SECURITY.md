# Security Policy

## Supported Versions

We only provide security updates for the latest stable release of the DXD Audit Kit.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

**DO NOT** use the public issue tracker to report sensitive security vulnerabilities in the kit itself (e.g., issues in the `Scripts`, `Parser`, or `CI` that could be exploited).

Please report security vulnerabilities by emailing: **<security@dxdlabs.dev>**

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Scope

This policy applies to:

1. All scripts in `scripts/` and root.
2. The vulnerability database parsing logic.
3. The official PoCs (if they contain dangerous exploits that are not safely encapsulated for testing).

*Thank you for helping keep the Sui ecosystem safe.*
